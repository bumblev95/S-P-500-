사이트 접속과 외부 리소스

페이지를 불러오면 호스팅 서비스 GitHub Pages와 외부 리소스 제공자에게 IP 주소·브라우저 정보·요청 시각 등의 접속 정보가 전달될 수 있습니다. 차트·아이콘 등의 외부 라이브러리를 읽을 때도 해당 제공자에게 접속 요청이 발생할 수 있습니다. 이 서비스들의 접속 기록은 각 제공자의 정책에 따라 처리됩니다.

외부 뉴스·원자료·광고·문의 링크를 열면 해당 사이트의 개인정보 처리방침이 적용됩니다. GitHub 개인정보 안내

브라우저 저장과 개인 거래 계획

관심종목·가치 가정·일부 화면 설정·통계 동의 선택은 브라우저 저장 공간(localStorage)을 사용할 수 있습니다. 개인 거래 계획 입력과 계획 파일 불러오기는 기기 내 브라우저에서 처리하며, 매입가·수량·파일 내용을 사이트 서버에 업로드하지 않습니다. 직접 저장한 파일은 이용자 기기에 보관됩니다.

브라우저의 사이트 데이터 삭제 기능으로 저장값을 삭제할 수 있습니다. 삭제하면 관심종목·가정·동의 선택도 초기화될 수 있고, 다운로드한 파일은 별도로 삭제해야 합니다. 다른 기기로 개인 계획을 자동 동기화하는 기능은 제공하지 않습니다.

방문·사용 통계

사이트 개선을 위해 Google Analytics 4로 페이지 방문과 공개 종목 조회, 검색 결과 선택, 예측 기간·모의운용 탭 등 기능 사용을 측정합니다. 통계 수집은 이용자가 ‘허용’을 선택한 뒤 시작합니다. Google에 접속·기기·브라우저 정보와 사용 이벤트가 전달되고 분석용 쿠키가 사용될 수 있습니다.

직접 보내는 이벤트에는 검색어 원문, 거래 계획의 매입가·수량, 파일 내용과 개인정보를 포함하지 않습니다. 통계 페이지 주소에서 입력 쿼리와 해시를 제외하고, 이 분석 태그의 Google 광고 신호와 광고 개인 최적화를 비활성화합니다.

선택은 이 브라우저에 저장됩니다. 거부하면 분석 태그를 불러오지 않으며, 이미 허용했던 경우 이후 전송을 중단하고 루트와 프로젝트 경로의 분석 쿠키를 삭제합니다. 쿠키 삭제가 이미 수집된 통계의 소급 삭제를 뜻하지는 않습니다.

광고와 쿠키

현재 사이트의 수동 광고 기능은 비활성화되어 있습니다. 사이트 소유권 확인용 AdSense 계정 메타 태그는 그 자체로 광고를 요청하지 않습니다. 실제 광고를 활성화하면 광고 영역에 ‘광고’를 표시합니다.

광고 게재 시 Google과 제3자 광고 제공자는 광고 제공·측정·부정 이용 방지를 위해 쿠키, 웹 비콘, IP 주소 또는 기기 식별자를 수집·공유·사용할 수 있습니다. 제3자는 브라우저에 쿠키를 저장하거나 읽을 수 있습니다.

Google과 광고 파트너의 광고 쿠키는 이 사이트 또는 다른 사이트에 대한 이전 방문을 바탕으로 맞춤 광고를 제공하는 데 사용될 수 있습니다. 맞춤 광고 선택은 Google 광고 설정에서 관리할 수 있습니다. 일부 제3자 광고 제공자의 맞춤 광고 선택은 Digital Advertising Alliance 선택 안내에서 관리할 수 있으며 브라우저 설정에서도 쿠키를 관리할 수 있습니다.

동의 선택과 광고·분석의 구분

하단 ‘방문 통계 설정’은 Google Analytics 통계 선택입니다. 이 버튼은 광고 동의 관리 도구가 아닙니다. 광고를 게재할 때 적용되는 광고 개인정보 메시지가 표시되면 해당 메시지에서 동의와 설정을 관리합니다. 필요한 지역의 광고 동의 설정은 별도 광고 동의 관리 플랫폼을 사용해야 합니다.

광고와 분석은 구분해 표시하며, 광고가 추세 점수나 TOP3 선정 규칙을 바꾸지는 않습니다. 수집·광고 제공 방식이 바뀌면 이 안내를 갱신합니다.
