# 126일 biasCorrected 실패 원인과 다음 실험

이번 보정은 개선으로 인정할 수 없다. **동일한 최종 검증 1,996행·4개 시점에서 가격 MAPE, 수익률 MAE, 큰 오차, 방향 정확도가 함께 악화됐다.** 별도 방향 분류기와 결합 후보도 공동 평가를 통과하지 못했으므로 선택한 후보는 없다. 모든 숫자는 PIT 미완성 자료의 격리된 과거 진단이며, TOP3·홈페이지·실전 모델·매매 규칙은 변경하지 않았다.

## 1. 무엇을 같은 표본에서 비교했나

평가 시점은 2024-10-03, 2025-04-07, 2025-10-07, 2026-04-09이다. 각 126거래일 결과 창은 겹치지 않고 경계 종가만 공유한다. 기존 원본 전체 5,919행이나 보정이 가능한 전체 3,479행을 최종 평가 1,996행과 섞지 않았다. 모든 후보는 같은 symbol/origin 키를 갖는다. 누락·중복·미성숙 target·비정상 입력은 일부 행 삭제 대신 실행 전체를 차단한다.

각 origin의 총 가중치를 동일하게 한다. Price MAPE = mean(|예측 가격비율 / 실제 가격비율 − 1|), 수익률 MAE = mean(|예측 가격비율 − 실제 가격비율|)이며 후자는 수익률 차이의 %p 단위다. 방향은 종료 가격비율 <0.98 하락, >1.02 상승, 나머지 보합이다. 최대 보유기간 낙폭은 이 target과 다르다. 하락 경고 오류율(FPR)은 실제 보합/상승 종목 중 하락으로 분류한 비율이며, 하락 경고의 오답 비율(1−precision)과도 다르다.

하위집단은 각 집단에 존재하는 origin을 동일 가중하여 비교한다. 전체 MAE 악화 원인의 기여도는 별도로 전체 표본 가중치를 고정하여 합산한다. 하위집단 평균을 단순 합산하면 전체 값이 되지 않는다. 보합/상승/하락 재현율과 precision은 전체 date weights의 조건부 비율이다.

## 3. 평균과 방향이 동시에 실패한 이유

**확인된 구조:** 보정값은 각 origin 이전에 완전히 만료된 최대 12개 origin의 log residual 중앙값에 0.5를 곱한 공통 이동이다. 최종 네 origin의 이동은 +0.002979, +0.004140, −0.003561, −0.000499 log ratio다. 종목별 방향 정보는 추가하지 않는다. 기존 모델은 최종 표본에서 하락 예측을 단 한 건도 하지 않았다. 이 작은 공통 이동 역시 실제 하락 849행을 하락으로 바꾸지 못한다.

방향이 바뀐 75행 중 맞던 분류가 틀린 분류로 된 것이 39행, 반대로 개선된 것이 4행이다. 나머지 32행은 두 방식 모두 오답이다. 숫자 예측이 ±2% 경계 가까이에 몰린 상황에서는 작은 공통 이동도 상승→보합 전환을 많이 만들어 방향 점수를 낮춘다. 방향이 달라졌다는 사실이 새 방향 정보가 생겼다는 뜻은 아니다.

**목적함수 불일치:** date-weighted log residual 중앙값은 가격비율 MAE와 가격 MAPE의 직접 최적값이 아니다. 공통 multiplier a로 기존 가격비율 f를 보정하면 MAE 최적 a는 실제비율/f의 f-weighted median, MAPE 최적 a는 같은 비율의 (f/actual)-weighted median이다(각 식에 기존 date weights도 곱한다). 현재 보정은 추가 f 또는 f/actual 가중치를 사용하지 않는다. 50% 축소는 변동을 줄이지만 목표함수를 일치시키지는 않는다.

**조건부 편향과 시간 변화:** 상승 집단 오차는 조금 줄고 하락 집단 오차는 늘었다. 하나의 pooled 이동이 두 집단을 동시에 개선하지 못했다. 과거 중앙값이 다음 origin의 조건부 오차를 잘 대표하지 못했을 가능성이 있다. 다만 사후 4개 시장 시점만으로 그 원인을 특정 경제 이벤트나 보편적 체제 변화로 확정할 수는 없다.

**모델 선택과 통과는 다르다:** biasCorrected는 과거 완료된 2023-04-03/2023-10-03 두 시점에서 regimeBlend보다 MAE + 0.25×p90 수익률 오차가 작아 선택됐다. 기존 모델이나 단순 기준보다 우수하다는 뜻이 아니다. 최종 average gate는 MAE <0.98×세 baseline 중 최저 MAE(약 20.358%p)를 요구하지만 보정 MAE는 20.787%p다. Tail도 최소 baseline p90보다 커서 실패한다. 날짜별 세 baseline 모두를 이긴 것은 2/4=50%로 60%에 미달한다. 방향은 original과 always-up 기준 중 높은 것을 넘어야 한다.

**표본 수:** 1,996행은 1,996개 독립 시장 실험이 아니다. 네 날짜 블록을 재표집한 보정의 MAPE 개선률 차이 95% 기술적 구간은 약 **[−0.17014, +0.05515]%p**로 0을 포함한다. 이 부트스트랩도 4개 시점의 작은 자료에 의존하는 설명용 구간이다. 기존 enoughDates=4 통과를 강한 통계적 검증 완료로 해석하지 않는다.

## 4. 가격 유지 분류기와 결합 방식의 실제 비교

가격 유지 후보는 원본 ratio를 그대로 복사한다. 가격 수정이 없으므로 MAPE와 수익률 MAE도 원본과 정확히 같다. 방향 정보는 별도 필드이며 생산 시스템에 보내지 않는다. Logistic/균형 Logistic/HGB는 origin 이전의 mature OOS 원본 예측과 기술 지표로 학습한다. 최근 2개 완료 origin은 별도 logistic calibration에 사용하고, fit target이 calibration origin까지 겹치면 purge한다. PR #25의 동일 시간 분리 함수와 라벨·date weighting·확률 클래스 정렬을 재사용했다.

균형 학습은 클래스 빈도의 역제곱근 가중, 트리는 45 iterations/7 leaves/L2=20, 로지스틱 C=0.1이다. 각 모델의 보정 확률 평균이 directionEnsemble이고, conservativeDown은 pDown >=0.65와 pDown>pUp일 때만 원본 방향을 하락으로 바꾼다. 그 외 후보는 고정 argmax다. 결과를 보고 임계값을 다시 선택하지 않았다.

가격 결합은 original/noChange/trend의 가격비율을 0.25 단계 convex grid로 조합한다. 과거 완료 origin의 MAPE 최소값으로 causalMapeBlend를 선택한다. causalJointBlend는 동시에 방향/precision/FPR/up-recall/tail 조건을 만족하는 조합만 허용하고, 불가능하면 원본으로 돌아간 사실을 기록한다. PR #25의 이미 실행된 공동 분포·conditional/relative/blend를 새 모델로 다시 만들지 않았다. 기존 regimeBlend의 재현값도 같은 최종 표본에서 비교한다.

- HGB는 849개 하락 중 379개를 포착했지만 925개 경고 중 **546개가 실제 보합/상승**이다. FPR 47.598%, 하락 precision 40.977%는 실제 하락 비중 42.580%보다도 낮다. recall 증가만 보면 잘못된 매도 경고를 성공으로 오인한다.
- Logistic의 정확도 상승은 상승 예측 비중 확대의 영향이 크다. 모든 argmax 분류기는 보합을 한 건도 맞히지 못하고, balanced accuracy도 원본 40.287%보다 낮다. 어느 분류기도 always-up 50.457%를 넘지 못한다. 보정 확률의 Brier도 fit-period prior보다 나빠 probability gate를 통과하지 못한다. 따라서 calibrated라는 학습 절차 이름을 실제 확률 검증 통과로 혼동하지 않는다.
- 확률 평균은 HGB보다 FPR을 줄이지만 **431개 경고 중 268개가 오답**이고 하락 precision은 37.820%다. 확률을 평균했다고 자동으로 오경보가 해결되지 않는다.
- 보수적 0.65 경고도 24건 중 **19건이 오답**, 실제 하락 포착은 5건뿐이다. threshold를 높이는 것만으로 정확한 경고를 확보하지 못했다.
- 고정 90:10은 MAPE를 19.154%로 조금 낮추지만 수익률 MAE가 20.890%p로 악화되고 방향 정확도는 36.580%, 하락 포착은 여전히 0%다. 공동 개선이 아니다.
- causalMapeBlend는 앞 세 origin에서 noChange, 마지막에서 50:50 original/noChange를 골라 최종 MAPE 19.812%로 악화됐다. 과거 error winner가 다음 구간 winner는 아니다.
- causalJointBlend는 네 origin 모두 제약을 충족하는 조합이 없어 원본 fallback이다. 원본 성과를 새로운 개선으로 발표하지 않는다.

기존 original/noChange/trend의 전체 표본 signed return-error 상관은 각각 original↔noChange **0.982**, original↔trend **0.958**, noChange↔trend **0.989**다. 이는 설명용 pooled Pearson이며 과거 origin별 fold 선택과는 무관하다. 이름이 다른 가격 예측들이 공통 실현 수익률 오차를 크게 공유하여 결합의 이득이 제한된다. 독립적인 오차 정보가 필요하다는 PR #25의 기존 결론과 일관된다.

## 5. 공동 기준과 승격 금지

공동 평가에는 가격 MAPE·수익률 MAE·90백분위 APE가 원본보다 나빠지지 않는 조건, 하락 포착 +3%p, 하락 precision의 시장비중 대비 +5%p 우위, FPR 악화 없음, 상승 포착/균형 정확도 악화 없음, 원본·always-up보다 높은 정확도, 최소 30 경고, 날짜별 60% 이상 공동 비열화 없음, date-block 불확실성을 적용했다. 확률 후보에는 Brier<prior Brier 조건도 있다.

현재 원본은 하락 경고를 전혀 하지 않아 FPR=0이다. **FPR 비악화**를 문자 그대로 적용하면 새 후보는 잘못된 경고를 하나도 만들 수 없어 엄격하다. 이것을 알고 gate를 유지했다. 이미 본 결과에 맞춰 tolerance를 완화하지 않았다. 향후 허용 오경보 수준을 정한다면 독립된 다음 프로토콜에서 미리 결정하고, 상한 신뢰구간 및 경고 coverage/precision을 함께 등록해야 한다. 실제 매도 허용 기준은 예측 연구의 cutoff와 별도로 정해야 한다.

모든 후보가 공동 gate에 실패했다. 또한 **PIT complete=false**, **untouched prospective=false**, **독립 최종 origin 4<8**이므로 수치 gate가 우연히 좋아도 승인되지 않는다. source generation 2026-10-09, adapter/status generation 2026-10-12를 구분한다. 252일은 기존 insufficient 그대로이며 신규 252일 연구 성과를 주장하지 않는다.

PR #25의 PIT audit 0/34, lifecycle blocked 판정을 원본과 해시가 같은 사본으로 보존했다. 34개의 기존 origin 증거가 새 네 origin에도 완전하다고 가정하지 않았다. 새 origin의 full PIT readiness 역시 0이다. 당시 구성종목·영구 issue identity·가격 vintage·삭제/합병/상장폐지 최종권리와 cohort outcome이 완전해지기 전, 이 표는 실전 검증 결과가 될 수 없다. 종료가격 방향과 보유기간 낙폭을 분리한 PR #25 연구도 그대로 재사용하고, 이번에는 경로 자료를 새로 수집하지 않았다.

## 6. 다음 실험을 구체적으로 어떻게 바꿀까

1. **입력부터 검증:** PR #25의 기존 PIT/lifecycle export gate를 재사용한다. 당시 origin의 전체 frozen cohort를 만들고, 탈락/합병/상장폐지 종목도 유지하며 누락 target은 원본 보유자산 가격과 shareholder wealth를 구분해서 처리한다. 과거 가격 발표 vintage가 없는 구간은 계속 quarantine한다. 단순 ticker 교체나 survivor 교집합으로 메우지 않는다.
2. **가격 유지 방향 실험 v2:** 현재 original numeric endpoint를 동결한다. 새로운 후보는 (a) 보합/비보합을 먼저 구분하는 계층 분류 후 상승/하락 분류, (b) 기존 3-class calibrated 분류다. 현재 argmax의 보합 collapse를 명시적 실패 가설로 삼는다. 하락 threshold는 mature nested calibration에서만 정하고, 최종 origin에서 재선택하지 않는다. 분류 확률/라벨은 numeric forecast와 별도 연구 필드로 두며 둘의 불일치율도 보고한다. 이 구조만으로 판매 추천은 만들지 않는다.
3. **오차 전문가의 다양성:** PR #25의 conditional/robust/relative 후보 결과는 그대로 재사용한다. 이미 실패한 동일 가격 전문가를 추가 이름으로 반복하지 않는다. 기존 예정된 future-market/stock-excess-return 실험과 연결하여, 알려진 사후 시장 수익률을 입력하지 않는 독립 시장 OOS 예측과 종목 초과수익 전문가를 별도 학습한다. origin별 잔차 covariance와 conditional error를 먼저 비교하여 원본과 높은 오차 상관만 가진 후보는 결합 후보에서 제외할 근거를 검증한다.
4. **수치 결합 v2:** f=Σwᵢfᵢ, w≥0, Σw=1를 유지하되 목적함수를 date-equal price MAPE에 맞춘다. 과거 mature OOS 예측의 내부 calibration에서만 weights를 정하고 return MAE·p90·방향/FPR/precision 제약을 함께 검사한다. 개선 가능한 조합이 없으면 original fallback을 기록한다. 방향 확률을 numeric 가격의 부호로 강제 주입하거나, precision이 낮은 classifier로 가격을 음수 방향에 route하지 않는다.
5. **검증 설계:** PIT-complete 역사에서 horizon embargo를 갖춘 nested walk-forward와 최소 8개 비중첩 final origin을 확보한다. 새로운 미래 발표는 origin/input/model/protocol hash를 불변 기록하고 월별로 수집할 수 있다. 월별 126일 창은 서로 겹치므로 12개월 발행을 12개 독립 관측으로 세지 않는다. horizon을 반영한 block inference와 non-overlap 재평가를 모두 제시한다. 이미 본 네 origin을 untouched test라고 다시 이름 붙이지 않는다.
6. **공동 판단 유지:** MAPE·return MAE·tail 비악화 + 하락 recall/precision + false-warning 통제 + 상승/보합 재현율 + 확률 검증 + 날짜별 일관성을 동시에 본다. 모델·임계값 다중 비교 수를 등록하고, 한 항목 개선으로 다른 실패를 상쇄하는 합산 점수만으로 승인하지 않는다. 실제 매매 규칙은 별도 whole-account turnover/수수료/slippage/stress-cost 검증을 통과해야 검토하며, 이번 분류 성적을 매매수익으로 환산하지 않는다.

v2는 위 입력 의존성이 충족된 뒤 별도 frozen bundle에서 실행한다. 이번 v1에서는 미래 데이터나 미완성 PIT 자료를 검증 완료로 만들지 않았고, 최종 후보를 선출하지 않았다.
