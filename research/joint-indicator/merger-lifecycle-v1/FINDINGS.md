# 합병·상장폐지 이후 주주 가치 추적

**구현은 완료했지만 실제 과거 데이터 준비 상태는 여전히 0/34입니다.**
이번 추가는 연구용 계산·검증 모듈입니다. 새로운 실제 수익률이나 모델 성과를
산출한 작업이 아닙니다. 기존 예측, 연구 결과, PIT 및 FJA quarantine 파일은
변경하지 않았습니다.

## 구현한 처리

| 상황 | 처리 |
|---|---|
| 현금 인수 | 실제 지급이 확인된 현금을 기록하고 평가일까지 무이자 현금으로 유지 |
| 주식 교환 | 영구 종목 ID와 확인된 교환 비율로 후속 주식 수량 추적 |
| 현금·주식 혼합 / 연속 합병 | 각각의 자산을 최초 종목의 평가 행 아래에서 계속 추적 |
| 배당·분할 | 배당은 현금으로 누적하고 분할은 수량에 반영; 조정주가와 이중 계산 금지 |
| 조건부 추가 지급 권리 | 별도 자산으로 보존; 실제 지급·소멸이 확인되기 전에는 총수익률 차단 |
| 확정된 무가치 소멸 | 0원과 -100% 수익률을 유지; 자료 누락과 구분 |
| 지수 편출 / ticker 변경 | 평가 대상에서 제거하거나 자동 매도하지 않음 |
| 평가일 이후 현금 지급 | 평가일의 미확정 채권으로 남기고 나중에 받은 돈을 앞당겨 넣지 않음 |
| 정정 공시·가격 수정 | 당시 평가 시점에 알려진 버전만 사용 |

주식 교환은 후속 기업의 가격을 원래 기업의 주가로 붙이는 방식이 아닙니다.
최초 보유 주식이 어떤 현금과 주식·권리로 바뀌었는지 장부로 이어갑니다.
후속 기업이 다시 합병되거나 상장폐지돼도 그 결과는 최초 종목의 행에 연결됩니다.

원래 주식이 소멸했다면 원래 종목의 미래 주가 오차는 계산 대상이 아닙니다.
따라서 **주주 총수익률 오차와 원래 종목 주가 오차를 별도로 평가**합니다.
기존 모델의 주가 예측을 총수익률 예측이라고 이름만 바꿔 사용하지 않습니다.
전체 평가 대상 중 일부만 남겨서 성과를 좋게 보이는 계산도 차단합니다.

## 실제 자료의 현재 상태

기존 SEC WBA 공시 원본과 해시를 그대로 보존했습니다. 공시에 관측된
주당 $11.45 현금과 최대 $3의 추가 지급 권리는 **미해결 관측 기록**입니다.
최대 지급액을 확정 수익으로 가정하지 않았으며, 이 bundle에는 검증된 영구
종목 매핑·전체 배당/기업행위 이력·평가일 가격·정산 데이터가 없습니다.
정규화된 자산/거래/가격/coverage 테이블은 비어 있고 실제 계산 결과도 0건입니다.

34개 origin은 기존 구성원·sector·identity/alias·publication-vintage 증거
부족 때문에 계속 차단됩니다. 이제 자료를 확보했을 때 합병 대가를 계산하고
안전하게 검증할 코드와 입력 계약이 추가된 상태입니다.

## 검증

- 신규 43개와 기존 96개, 총 **139개 로컬 회귀 테스트 통과**.
- 현금, 주식, 혼합 지급, 연속 합병, 배당, 분할, 권리 지급/소멸, 후속 기업의
  미해결 상장폐지, 미래 지급, 늦은 정정, 누락 가격·증권 ID 등을 검증.
- 테스트의 가상 사례는 `synthetic_fixture`로 표시하며 실제 데이터로 승격하지 않음.
- 기존 71개 파일의 SHA256과 세 audit의 정확한 재현을 확인.
- 새 outcome export와 기존 두 cohort export는 실제 미완성 입력에서 종료 코드 2,
  출력 파일을 만들지 않음.
- 새 workflow는 읽기 전용이며 예약 실행, 모델 학습, production 변경을 포함하지 않음.

코드: `scripts/research_merger_lifecycle.py`. 입력 규격: `INPUT-CONTRACT.md`.
모든 origin의 차단 사유와 미해결 관측: `coverage-audit.json`.
