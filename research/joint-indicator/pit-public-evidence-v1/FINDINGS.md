# 공개 자료 PIT 보강 결과

**개별 공식 변경 증거는 늘었지만, 완전한 과거 투자 가능 종목 집합은 아직 검증되지 않았다.**
PIT 준비 상태 0/34, 기업 생애주기 준비 상태 0/34, 실제 계산한 수익률 0을 유지한다.
새 모델 학습·성능 평가·실전 적용을 수행하지 않았다.

## 무엇을 보강했나

PR #25의 계약과 감사 도구를 그대로 사용하고, 별도 `pit-public-evidence-v1`
입력 묶음을 만들었다. 기존 공식 공시 원본 5개, 34개 기준일, FJA 후보 관측,
WBA 미해결 관측을 재사용했다. 이전 브랜치의 1,155개 파일은 해시로 보존했다.

공식 S&P 변경 공시 18건에서 편입·제외 사실 62개를 추가했다. 발표일,
보수적 이용 가능 시점, 적용 시점, 표의 행, 거래소, 당시 섹터를 분리했다.
기존 8개를 포함한 공식 변경 관측은 70개다.

| 후보 변경 기록 대조 | 이전 | 이번 보강 |
|---|---:|---:|
| 일치 | 8 | 68 |
| 불일치 | 0 | 2 |
| 미확인 | 1,526 | 1,464 |
| 전체 | 1,534 | 1,534 |

일치는 **티커·편입/제외·적용일 세 필드의 대조**다. 후보 자료의 당시 공개
시점이나 영구 종목 식별자, 빠진 변경이 없다는 사실까지 인증한 것이 아니다.
후보 기록의 `historicalKnownAt`와 `securityId`는 계속 null이다.

## 먼저 살펴볼 기준일

1순위는 **2025-02-07과 2025-04-25**다. 직전 기준일 이후 후보 변경이
각각 8건이며 이번 공식 공시로 8건 모두 대조됐다. 변경 구간이 짧고 최근
공식 문서 접근성이 좋아서 먼저 선정했으며, 모델 성과로 선택하지 않았다.
당시 전체 구성종목 기준표·완전한 변경 이력은 별도로 필요하므로 둘 다
통과 상태가 아니다.

2024-10-11은 18건 중 16건 대조, SW/WRK 두 기록은 미확인이다.
2025-10-31은 20건 중 18건 대조, PARA/PSKY 두 기록은 지수 편입·제외
증거가 미확인이다. 기업 합병·거래 시작 공시를 지수 변경 공시로 대신하지 않았다.
2023-03-24는 GICS 전환과 은행 실패를 점검할 3순위로 두되, 완전한
분류·종료가격·배당/회수 이력은 확보되지 않았다. 전체 34개 기준일은 CSV에 보존했다.

## 중요한 차이와 시점

**Solventum:** 2024-03-27 공시의 각주는 4월 1일 개장 전 산업재 편입,
4월 3일 개장 전 헬스케어 변경을 명시한다. 표의 `Health Care*`를
편입일부터 적용하지 않고 두 섹터 이벤트로 저장했다.

**VFC·XRAY:** 후보 자료는 각각 4월 1일·2일 제외로 기록하지만, 같은 공식
공시 표는 두 종목 모두 4월 3일 제외로 기록한다. 후보 자료를 수정하거나
근처 날짜 일치로 처리하지 않았다. 실제 최종 적용일을 해소할 독립 공시,
정정 이력 또는 당시 지수 파일이 필요하다. 발표 본문에서 새 종목이 기존
종목을 대체한다고 한 날짜만으로 표의 별도 제외일을 덮어쓰지 않는다.

**Discover:** 2025-05-18 합병 완료 발표, 5월 19일 지수 제외, 5월 19일
SEC 공시 제출을 분리했다. SEC 문서의 1.0192 COF 주식 교환 비율은
제출일 다음 뉴욕 자정부터 알 수 있는 관측으로 저장했다. 분수 주식의
현금 처리·실제 지급·배당·기준일 평가가격이 없어 최종 수익률은 미해결이다.
COF 가격을 소멸한 DFS 원주 가격으로 대체하지 않았다.

**Paramount:** 기존 기업 CIK 0000813828, 새 기업 CIK 0002041610,
기존 PARA/PARAA와 새 PSKY의 주식 종류를 문서별로 보존했다.
8월 6일 전환과 7일 합병, Class A/B의 선택 조건을 구분한다. Class B 현금
선택에는 문서상 약 0.60925910 안분 계수가 적용됐다. 사용자가 무엇을
선택했는지, 실제 지급 단위·시점은 가정하지 않았다. 단순 티커 변경이나
일괄 $15 청산으로 처리하지 않는다. 지수 변경 기록도 별도로 미확인이다.

**GICS 2023:** 구조 개편 발표와 시행 예정 시점은 확보했다. 2022년 6월
선택 기업 목록 공시는 최종 적용 전 변경 가능성을 명시한다. 최종 고객용
기업별 분류표는 확보하지 못했으며 Visa/Mastercard 등의 섹터를 추정 입력하지 않았다.

원본 자료 수집에 한계도 있다. 신규 저장 38건 중 37건은 공개 웹 도구가
반환한 **추출 페이지**, 1건은 FDIC 접근 실패다. 저장 바이트·해시·조회
시각·공식 주소는 보존했지만, 원래 HTTP HTML/PDF 바이트를 확보했다고
표시하지 않았다. S&P 직접 요청은 HTTP 403이었다. 추출 페이지의 스키마
검사 통과는 계약의 원본/과거 수정 빈티지 인증 통과가 아니다.
FDIC 실패나 은행 주주 보호 부재를 최종 회수액 0으로 바꾸지 않았다.

다음 작업은 1순위 두 기준일의 공식 security-level 전체 기준표와 모든

범위에서 받을 수 있는 공식/공급업체 export의 계약·빈티지·식별자를 확인해야
한다. 유료 계약이나 추가 지출은 시작하지 않았다. 가격·기업 생애주기
자료까지 충족한 뒤 별도 실험을 등록해야 수익률 오차와 방향 정확도 개선을
신뢰성 있게 비교할 수 있다.
