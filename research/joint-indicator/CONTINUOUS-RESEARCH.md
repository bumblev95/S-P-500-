# 지속적인 진입 지표·방향·수익률 연구

사용자 지시(2026-10-03, America/Regina): 웹 화면은 그대로 유지한다. 상승과 하락을 모두 구별하면서 수익률 오차를 줄이는 방법을 사용자가 다시 묻지 않아도 계속 찾고 연구한다.

## 연구 실행 원칙

1. 직전 연구 기록과 최신 main의 데이터·모델을 먼저 읽는다. 단순 재생성 시각 변경은 신규 성능 개선으로 보고하지 않는다.
2. 새 논문·공식 문서·재현 가능한 연구에서 근거를 찾는다. 인플루언서 주장만으로 지표의 우위를 인정하지 않는다.
3. 한 차례에 최대 두 개의 새로운 가설을 검사한다. 코드 실행 전 후보, 입력, 기간, 문턱, 비용, 평가 구간을 별도 프로토콜에 고정한다. 실패한 가설도 남긴다.
4. 6개월(126거래일)과 1년(252거래일)은 분리한다. 단기 진입·보유 대응 규칙과 장기 예측을 같은 정확도로 합산하지 않는다.
5. 같은 종목·날짜의 가격 불변, 항상 상승, 단순 가격 추세와 비교한다. 상승 포착, 하락 포착, 하락 경고 적중, 균형 방향 적중, 수익률 오차·큰 오차, 확률 성적을 함께 기록한다.
6. 학습·교정에는 예측 기준일 전에 결과가 확정된 자료만 사용한다. 겹치는 미래 관측 구간을 제거하고 날짜별 가중치를 맞춘다. 생존 편향과 공시·가격 자료의 수정 가능성을 밝힌다.
7. 이미 검토한 과거 평가 자료에서 좋아진 결과는 탐색 결과로 기록한다. 새 발행 후 결과를 보존하고, 미래 관측이 쌓인 뒤 별도로 평가해야 한다. 과거 자료로 재생성한 전망은 실제 발행 기록으로 넣지 않는다.
8. 상승·하락 비율을 임의로 맞추거나, 분류와 수익률의 부호를 억지로 맞추지 않는다. 횡보와 판단 불확실을 구분하고 보류한 비율·전체 표본 성적도 보고한다.
9. 매매 지표의 수익성을 주장할 때는 다음 거래일 체결, 거래비용·회전율·낙폭 및 단순 보유 기준을 포함한다. 가격 예측 개선만으로 매매 성과 개선을 주장하지 않는다.
10. 연구 전용 코드·자료·문서와 Draft PR까지는 진행한다. 웹 화면, 서비스 예측 파일, 매수/매도 순위, 실전·모의운용 정책, 자동 승격 기준을 변경하거나 PR을 자동 병합하지 않는다.

## 이번 기준 실험

- `PROTOCOL.json`: 실행 전에 고정한 공동 분포 세 후보.
- `scripts/research_joint_indicator.py`: 기존 외부표본 예측으로 학습하는 메타 모델. 학습 결과 확정일 < 교정 시작일 < 교정 결과 확정일 < 새 예측일을 확인한다.
- `results.json`, `RESULTS.md`: 실패를 포함한 동일 표본 비교와 입력·프로토콜 해시.
- 웹 서비스의 pooled HGB와 이 연구의 가격 패턴 모델은 다르므로 직접 우위 비교로 해석하지 않는다.

```bash
python scripts/test_joint_indicator.py
python scripts/research_joint_indicator.py --source research/environment.json --output research/joint-indicator
```

동일 sourceHash와 동일 프로토콜·코드에서의 재실행은 새로운 실전 증거가 아니다. 미래 연구가 결과를 덮어쓰기 전에 날짜·버전별 결과를 보존하고 Git 변경 이력을 남긴다.

## 다음 가설의 우선순위

1. **시장·업종 움직임과 종목 고유의 강약 분리.** 절대 수익률과 시장 대비 수익률을 별도 목표로 학습하고, 당시 확보 가능한 시장·업종 예측을 결합한다. 상대 약세만으로 절대 하락을 단정하지 않는다.
2. **방향별 수익률 크기.** 이번 단순 클래스별 과거 분포 대신 조건별 분포·분위수 추정을 비교한다. 방향 개선이 가격 오차 악화로 이어지는지 확인한다.
3. **자료 범위.** 당시 지수 구성·상장폐지 기업·기업행동과 당시 공개된 실적 변화를 보강한다. 입력 증가만으로 성능 개선을 주장하지 않는다.
4. **하락 경고의 경제적 효용.** 하락 종료값과 기간 중 낙폭을 별도 목표로 평가한다. 연말 회복 전망이 기간 중 위험을 가리는 문제를 검사한다.
5. **단순 지표 기준.** 이동평균·돌파/이탈·시장 대비 강도와 새 후보를 동일 체결 규칙으로 비교한다. 보유 대응의 좋은 지표와 신규 진입의 좋은 지표가 다를 수 있다.

## 사용자에게 전달할 내용

새로 검사한 방법, 동일 표본에서 실제로 개선/악화한 항목, 승격 여부, 다음 가설을 한국어로 짧게 보고한다. 의미 있는 변화 없이 같은 결과만 반복하지 않는다. 새로운 실험의 실패나 자료·검증 문제도 기록하고 첫 확인 때 알린다. ‘최고’나 성공 확률을 근거 없이 보장하지 않는다.
