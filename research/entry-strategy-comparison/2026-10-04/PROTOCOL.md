# 대체 진입 전략 비교: 고정 프로토콜

2026-10-04에 결과 계산 전에 고정한 탐색적 비교다. 실시간 `buy` 판정,
홈의 매수 TOP, 진입 대기 후보와 기존 forward 관측·계좌는 수정하지 않는다.
현재 전략의 임계값을 조정하는 실험이 아니다.

## 입력과 공통 실행

- 앞선 `entry-context-v1-retrospective-v1` 연구의 가격 버전을 재사용한다.
  정규화 가격 SHA256은
  `0307d3266187abea5e008fbaefd71a447d78298365ff41d2f7939516a12cf92a`.
  현재 홈의 505개(현재 구성 종목 503개, SPY·SOXX)를 포함한다.
- 2017-10-02~2026-10-02의 SPY 거래일. 가격은 동일한 Yahoo quote OHLC,
  배당·세금·환율 제외. 대체 모델은 원 정밀도 OHLC로 신호를 계산한다.
  현재 규칙의 대조군은 기존 연구의 현행 CSV 반올림 방식과 결과를 그대로 쓴다.
- 지표는 해당 종가까지의 데이터만 사용한다. SMA 5/20/50/200,
  직전 55일 고가·20일 저가(당일 제외), 단순 평균 TR 20일,
  63일 수익률, Wilder RSI(2)를 계산한다. RSI 초기값은 첫 2개 변화의
  평균이며 이후 재귀 평활한다. 등락 모두 0이면 RSI=50.
- 대체 모델은 SPY 달력상 실제 연속 200봉 이후만 신규 진입한다.
  누락·상장 전 데이터를 보간하지 않는다. 지표의 미래 값은 읽지 않는다.
- 각 가상 계좌 $10,000, 기존 frozen paper engine의 위험 1%,
  최대 5종목, 진입 시 종목 비중 20%, 동일 업종 2종목, 정수 주식,
  현금·1배 한도를 쓴다. 이후 가격 변화로 늘어난 비중은 재조정하지 않는다.
  모든 후보를 해당 모델 순위로 주문하며 TOP3만 사는 계좌가 아니다.
- 종가 신호 뒤 다음 실제 시가에만 진입/종가 판단 청산한다.
  시가가 신호 가격에서 0.5 ATR 초과 이탈하면 취소, 신호 유효기간 5일.
  시가 청산을 먼저 실행해 현금을 확보하고, 이후 진입, 마지막으로 봉 내
  손절/목표를 실행한다. 당일 후반 손절 수입으로 당일 시가 진입을 하지 않는다.
  진입봉부터 손절, 같은 봉 손절·목표 동시 도달은 손절 우선,
  손절 갭은 실제 시가, 목표 갭은 목표가. 손절 상향은 다음 봉부터 적용한다.
- 정상 비용은 편도 수수료 0.05% + 불리한 슬리피지 0.05%.
  대체 모델마다 두 비용을 각각 2배로 한 스트레스 계좌도 별도로 계산한다.
  목표가 없는 모델은 frozen engine의 targetless 옵션을 쓰며
  고정 목표의 비용 손익비 검사는 적용하지 않는다. 위험·자금 한도는 유지한다.

## 고정 모델

모든 대체 모델은 **당시 SPY 종가 > 당시 SMA200**일 때 신규 진입하며,
SPY가 SMA200 이하로 마감하면 보유분을 다음 시가에 청산한다.
이는 과거 실제 가격 필터이며 신용·펀딩 상태를 복원한 것이 아니다.
신규 손절은 종가 − 2 ATR20, 그 폭이 종가의 8% 이하일 때만 주문한다.

| 모델 ID | 종가 진입 조건 | 순위 | 청산·보유 |
|---|---|---|---|
| `channel55` | 종가 > SMA200, SMA50 > SMA200, 63일 수익률 > 0, 종가 > 직전 55일 고가 | 63일 수익률 / (ATR20 / 종가) 내림차순 | 목표 없음. 종가 < 직전 20일 저가면 익일 시가 청산. 저가 채널로 손절 상향은 익일 적용. 시간 제한 없음 |
| `pullback20` | 위와 같은 종목 추세. 전일 저가 ≤ 전일 SMA20 + 0.35 ATR20, 당일 종가 > SMA20·전일 종가·당일 시가 | 위와 같음 | 진입 신호 종가 + 4 ATR20 목표(2R). 종가 < SMA50 또는 84번째 보유봉 마감 뒤 익일 시가 청산 |
| `rsi2` | 종가 > SMA200, 종가 < SMA5, Wilder RSI(2) < 10 | RSI(2) 오름차순 | 목표 없음. 종가 > SMA5, 종가 ≤ SMA200 또는 10번째 보유봉 마감 뒤 익일 시가 청산 |

동점은 현행처럼 `symbol.localeCompare` 오름차순. `channel55`는
단순 채널 모델이며 현행 점수·이격·진입 상태 판정과 별개다.
`rsi2`는 손절·시가 체결·시간 제한을 추가한 연구 변형으로, 원전 전략의
완전한 재현이나 그 문헌 성과의 재현을 주장하지 않는다.

## 비교와 해석

- 현재 규칙의 기존 stable/watch 가정 결과를 수정 없이 대조군으로 쓴다.
  항상 stable/watch는 **가정**이며 당시 실제 신용 상태가 아니다.
  대체 모델은 가격에 따른 SPY 필터·순위·청산까지 함께 바뀐다.
  결과 차이를 진입 조건 하나의 효과라고 주장하지 않는다.
- 전체 계좌: 마지막 보유분의 가상 청산 비용까지 반영한 수익률·CAGR,
  종가 평가 최대낙폭, 평균 노출, 청산 거래 수·승률·profit factor·비용을 보고한다.
- 시간 비교: 전반 2017-10-02~2022-12-30, 후반 2023-01-03~2026-10-02.
  같은 연속 계좌의 종가 평가 곡선을 분할하며, 보유분을 승계한다.
  후반 시작 자본은 2022-12-30 종가 평가액이다. 이 분할 수익률·CAGR은
  종가 평가 기준이고 구간 끝의 추가 가상 청산 비용은 넣지 않는다.
  매년 성적과 비용 2배 결과도 모두 공개한다.
- 사전 선택 규칙: 대체 세 모델 중 전반 종가 평가 CAGR이 가장 큰 모델을
  기록하고 후반 결과를 확인한다. 동점은 모델 ID 순. 후반을 보고 전략이나
  임계값을 고르지 않으며, 모든 모델 결과를 공개하고 자동 승격하지 않는다.
- TOP3 진단: 매일 독립적인 상위 3개 신호의 익일 시가→20/63거래일 종가
  비용 반영 수익률 및 같은 날짜 SPY 대비 초과수익을 계산한다.
  구간 통계는 신호일과 종료일 모두 해당 구간 안인 관측만 사용한다.
  미성숙·결측·구간 경계 제외 수를 공개한다. 이는 손절 계좌 성과가 아니다.
- 빈 후보 비율과 평균 후보 수를 보고한다. 모든 모델에 억지 TOP3 채우기는 없다.
- 현재 구성 종목·업종, 상장폐지 누락, 공급자 수정·분할 조정, 배당 제외,
  겹친 일별 신호를 사용한다. 최근 구간도 이미 가격을 열람한 탐색적
  시간 분할이며 진정한 미관측 out-of-sample이나 역사적 구성 종목 검증이 아니다.
