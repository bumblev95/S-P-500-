# 방문·사용 통계 (GA4)

2026-10-04 · 측정 ID `G-0C529GQ91Z` · 공개 사이트 `https://bumblev95.github.io/`, `https://bumblev95.github.io/S-P-500-/`

## 설치와 집계 범위

현재 운영하는 프로젝트 경로의 14개 콘텐츠 페이지와 루트 메인 페이지가 공통 `assets/site-analytics.js`를 사용합니다.
즉시 이동하는 이전 주소와 보관된 레거시 화면은 집계하지 않습니다.
실제 공개 호스트의 프로젝트 경로와 루트 메인 `/`·`/index.html`에서만 Google 태그를 시작하며 로컬·미리보기와 다른 프로젝트는 제외합니다.
루트 페이지의 `base` 태그는 자산 경로에만 사용합니다. 방문 주소는 실제 위치에 따라 루트 메인은
`https://bumblev95.github.io/`, 프로젝트 메인은 `https://bumblev95.github.io/S-P-500-/`로 기록합니다.
쿠키 경로도 각각 `/`·`/S-P-500-/`이며, 기존 프로젝트 페이지의 URL과 쿠키 범위는 유지합니다.
통계 수집을 허용한 방문부터 쌓입니다. 설치 전 과거 방문을 복원하지 않습니다.
GA4의 사용자 수는 브라우저 식별 기반 통계이며 실제 사람 수와 정확히 일치하지 않습니다.
동의 거부, 브라우저 제한과 광고 차단으로 수집되지 않는 방문이 있습니다.

Google Analytics에 로그인하면 보고서에서 사용자 수·페이지 조회수·참여 시간 등을 확인할 수 있습니다.
실시간 보고서에서 설치 직후 테스트 방문과 이벤트를 확인합니다.
표준 보고서에는 처리 시간이 필요할 수 있습니다.

## 사이트에 추가한 이벤트

| 이벤트 | 의미 | 이벤트 매개변수 |
|---|---|---|
| `stock_view` | 실제 자료가 준비된 주식 상세 또는 고급 분석의 선택 종목 | `ticker`, `asset_type` |
| `coin_view` | 실제 자료가 준비된 현물·선물 종목 | `ticker`, `asset_type` |
| `search_result_select` | 한글·영문 검색에서 종목 선택 (클릭·Enter) | `ticker` |
| `feature_use` | 예측 기간·경로, 봉 주기, 섹터, 모의운용 계좌·탭 등의 선택 | `feature`, `choice` |
| `news_click` | 시장·회사 뉴스 링크 클릭 | `area`, `link_domain` |
| `nav_click` | 사이트 콘텐츠 페이지로 이동하는 링크 클릭 | `destination` |

모든 직접 전송 이벤트에 `page_name`을 포함합니다. 재렌더링·자동 갱신은 동일 종목 조회를 반복 기록하지 않습니다.
동의 전 이벤트를 소급 전송하지 않습니다. 동의할 때 현재 표시된 종목은 한 번 기록합니다.
검색어·거래 입력값·관심 및 보유 목록·파일 내용은 직접 전송하지 않습니다.
초기 페이지 URL은 쿼리·해시를 제외하고 referrer는 출처 도메인만 기록합니다.
Google signals와 광고 개인 최적화를 사용하지 않습니다.

## 종목·기능 순위 보기 (GA4 계정에서 1회 설정)

관리 → 데이터 표시 → 맞춤 정의 → 맞춤 측정기준 만들기에서 아래 항목을 **이벤트 범위**로 등록합니다.

| 표시 이름 | 이벤트 매개변수 |
|---|---|
| 종목 | `ticker` |
| 자산 종류 | `asset_type` |
| 사용 기능 | `feature` |
| 선택 옵션 | `choice` |
| 사이트 페이지 | `page_name` |
| 뉴스 영역 | `area` |

탐색 → 자유 형식에서 ‘종목’ 또는 ‘사용 기능’을 행으로, ‘이벤트 수’를 값으로 사용합니다.
종목 순위는 이벤트 이름 = `stock_view` 또는 `coin_view`, 기능 순위는 이벤트 이름 = `feature_use`로 필터링합니다.
맞춤 측정기준은 등록 후 보고서에 반영되기까지 처리 시간이 필요합니다.

향상된 측정의 페이지 조회는 브라우저 history 변경도 감지할 수 있습니다.
모의운용 탭 전환을 별도 페이지 조회에 포함하고 싶지 않다면
관리 → 데이터 스트림 → 이 웹 스트림 → 향상된 측정 설정 → 페이지 조회 고급 설정에서
‘브라우저 기록 이벤트에 따른 페이지 변경’을 끕니다. 문서 로드 시 기본 조회수는 유지됩니다.

## 동의와 본인 접속 제외

기본 동의 방식: 선택 전에는 Google 분석 스크립트를 요청하지 않습니다.
허용하면 Analytics 저장만 허용하고 광고 저장·광고 데이터·광고 개인 최적화는 거부 상태로 둡니다.
거부·철회 시 `ga-disable-<ID>`로 수집을 막고 같은 동의를 사용하는 루트·프로젝트 두 경로의 GA 쿠키를 지웁니다.
하단 ‘방문 통계 설정’에서 다시 선택할 수 있습니다. 선택은 같은 브라우저·탭에서 공유합니다.
운영자 본인 접속을 빼려면 자신의 브라우저에서 거부하거나 `?analytics=off`로 한 번 접속합니다.
`analytics=off`가 있는 주소에서는 UI·API·다른 탭의 허용으로도 수집을 다시 켤 수 없습니다.
이 매개변수를 제거한 페이지에서 다시 허용할 수 있습니다.
Google 태그 설치 테스트는 공개 사이트에서 먼저 통계를 허용한 뒤 실행합니다.
분석 동의 UI는 AdSense의 광고 동의 관리와 별개입니다.

## 확인

`node scripts/check_site_analytics_browser.cjs`는 실제 Google에 요청하지 않고 Playwright로
동의 전·거부 시 무전송, 허용·철회·다른 페이지에서 선택 유지, 재렌더링 중복 방지,
URL·검색어·거래 입력값 제외, 공개 호스트 제한과 모바일 배치를 검증합니다.
루트 메인과 프로젝트 14개 페이지 각각에서 실제 위치에 따른 URL·쿠키 경로, 초기 페이지 조회 1회,
스크립트 중복 로드·반복 허용 시 중복 초기화 방지, 두 경로 쿠키 철회, 탭 간 동의 공유와
`analytics=off`의 재허용 차단도 검증합니다. Google 요청은 테스트 응답으로 대체합니다.
기존 광고 설정과 화면 데이터·종목 판단은 변경하지 않습니다.
실제 GA4 계정에 이벤트가 수신되는지는 계정의 실시간 보고서에서 확인해야 합니다.
