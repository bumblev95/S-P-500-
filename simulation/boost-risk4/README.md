# 부스팅 5배 · 거래당 손절 예산 4% 진행 모의계좌

사용자 요청에 따라 108개 비교 조합 중 탐색 기준을 통과한 누적 수익 1위인 `boost_swing:risk4:5`를 새 기본 진행 모의계좌로 선택했다. 첫 자동 실행에서 $10,000으로 시작하며 정확한 시작 시각은 [experiment.json](experiment.json), 현재 잔액과 모든 거래는 [state.json](state.json)에 기록한다. 실제 주문·입출금은 없다.

## 규칙

- BTC·ETH·SOL 모두 5배, 격리 증거금, 동시에 1종목만 보유.
- 완료 4시간봉 14일 변화가 2 ATR을 넘고 직전 3일 고점·저점을 돌파하며 고정 부스팅 점수 ≥0.10 R일 때 롱·숏 후보.
- 거래당 최초 손절·왕복 수수료·슬리피지 기준 위험 예산은 현재 계좌의 4%. 최초 $10,000에서는 목표 $400이다. 가격 손절 거리 자체가 4%라는 뜻은 아니다.
- 증거금 90% 상한, 신호가 발생한 완료 15분봉 거래량과 직전 32봉 평균 중 작은 값의 0.5% 주문 한도. 연구와 같은 수량·추정 청산 함수를 사용한다.
- 초기·추적 손절 2.5 ATR, 모멘텀 반전 또는 30일 보유 종료. 고정 익절이나 부분익절 없음.
- 이번 선택안에는 기존 계좌의 일일 손실 제한·낙폭별 위험 축소·손실 연속 후 휴식을 추가하지 않는다. 미보유 잔고 $100 미만이면 신규 진입 중단.
- 편도 수수료 0.045%, 슬리피지 0.02%, 실제 시간별 펀딩. 누락된 정시 펀딩은 명목금액 0.01% 지급으로 가정하고 기록한다.
- 유지증거금 2.5%, 거래 OHLC를 마크가격 대용으로 사용. 강제청산 시 남은 격리 증거금 전액 손실로 처리한다. 실제 거래소의 규모별 증거금·호가·보험기금 엔진을 재현한 것은 아니다.

## 과거 결과와 진행 기록 구분

선정 근거는 2022-01-01–2026-08-31 Binance 선물 연구의 +424.64%, 최대 낙폭 37.24%, 212거래다. 이 값은 새 계좌의 시작 잔고나 거래 내역에 넣지 않는다. 과거 재현 탭에서는 이 고정 연구 결과를 표시한다.

진행 계좌는 기존 수집기의 Hyperliquid 공개 시세와 시간별 펀딩을 사용한다. 기존에 과거 자료만으로 학습하고 고정한 2026년 부스팅 모델을 사용한다. 모형 해시는 설정에 고정되며 변경하면 이 계좌를 덮어쓰지 않고 새 실험을 만들어야 한다.

신호를 실제 관측·기록한 뒤 시작하는 첫 가용 15분봉만 진입에 사용한다. 자동 작업이 늦게 실행되면 미기록 과거 진입 신호를 만들어내지 않는다. 추적 손절 변경과 모멘텀 청산 예약도 기록 시각 이후 시작하는 봉에만 적용한다. 이미 기록된 손절은 그 사이의 완료 봉으로 정산한다. 따라서 즉시 다음 봉을 쓰는 과거 연구와 진행 계좌는 같은 진입·배분 아이디어라도 관측 지연 및 시장 차이에 따른 성과 차이가 있다.

약 15분 간격 GitHub Actions 실행을 목표로 한다. 데이터 공백이나 가격 수정은 새 계좌의 체결을 보류시키며 경고를 남긴다. 계좌 시작·관측·예약·체결·청산은 이전 기록의 해시를 잇는 `ledger/` 파일에 추가된다. 재실행은 이미 종료한 거래를 바꾸지 않는다. 기존 모의계좌들은 원래 기록과 규칙으로 계속 유지된다.

검증: `node scripts/test_boost_risk4.cjs`. 관측 이후 체결, 늦게 확인한 추적선의 비소급 적용, 동일 관측 재실행, 자금·펀딩 정산, 연구 엔진과 체결·수량 일치, 기록 보존, 기본 화면 및 과거/진행 구분을 검사한다.
