# 동시 1종목 + 부스팅 모의 실험

목표는 실전에 쓰기 전, 매매 판단의 보조 지표로서 효과를 검증하는 것입니다. "최고 매매법"이 검증됐다는 의미가 아닙니다.

BTC만 고정 거래하는 방식이 아닙니다. BTC·ETH·SOL 중 조건에 맞는 종목을 확인하며, 기본 계좌는 **동시에 최대 1종목**만 보유합니다.

## 같은 시점에 시작하는 세 계좌

| 계좌 | 진입 | 동시 보유 |
|---|---|---|
| control-three | 14일 모멘텀 + 직전 3일 돌파 | 최대 3종목 |
| control-one | 같은 진입 규칙 | 최대 1종목 |
| boost-one | 같은 진입 규칙 + 부스팅 점수 0.10 R 이상 | 최대 1종목 |

각각 독립적인 가상 $10,000로 첫 배포 후 자동 실행 시 시작합니다. control-three와 control-one은 보유 한도의 효과, control-one과 boost-one은 ML 필터의 효과를 비교합니다. 여러 신호가 동시에 나면 원래 연구와 동일하게 추세 강도 순으로 다음 가격·보유 한도를 확인합니다. ML 점수가 가장 큰 종목으로 순위를 바꾸지 않습니다. 대기 후보가 여러 개여도 실제 동시 보유 한도는 지킵니다.

기존 모멘텀·6 ATR 계좌는 계속 운용합니다. 시작 시점이 달라 전체 누적 수익을 같은 기간 성과처럼 비교하면 안 됩니다. 새 실험과 기존 계좌 사이에 잔액·보유분·거래를 옮기지 않습니다.

## 진입과 청산

- 완료된 4시간봉의 14일 가격 변화가 해당 ATR의 2배를 넘어야 합니다.
- 롱은 종가가 직전 18개 4시간봉의 고가를 돌파하고, 숏은 저가를 이탈해야 합니다. 현재 봉은 돌파 기준 계산에서 제외합니다.
- 기본 ML 계좌는 2026년용 고정 부스팅 모델의 후보 순손익 점수가 0.10 R 이상이어야 합니다. 이 수치는 승률이나 확정 이익이 아닙니다.
- 초기·추적 손절 2.5 ATR, 모멘텀 반전, 최대 30일 보유. 이 실험에는 고정 6 ATR 익절을 추가하지 않았습니다. 검증한 돌파+ML 규칙을 그대로 사용합니다.
- BTC 5배, ETH/SOL 3배. 거래당 기본 위험예산 1%, 기존 증거금·명목 노출 한도, 낙폭에 따른 위험 축소, 일일 손실 제한, 3연속 손실 후 6시간 휴식을 유지합니다. 위험예산은 최대 실제 손실 보장 한도가 아닙니다.
- 편도 수수료 0.045%, 슬리피지 0.02%, 실제 수집 펀딩. 누락 펀딩은 기존 엔진의 보수적 가정으로 비용 처리합니다.

## 고정 모델과 관측 기록

`model.json`은 앞선 15년 현물/실제 선물 연구에서 학습했던 2026년 부스팅 후보를 숫자 트리로 내보낸 파일입니다. 학습 표본은 7,355개이며 학습 정답 종료는 2024년까지입니다. 자동 연도 선택기의 우승 모델이라는 뜻은 아닙니다. 과거 비교 후 사용자가 선택한 후속 모의 후보이며 새로운 미래 실적으로 평가해야 합니다.

고정 SHA256을 코드에서 확인하며, 파일이나 모델 버전이 달라지면 기존 계좌를 덮어쓰지 않고 계산을 중단합니다. 자동 재학습·모델 교체는 하지 않습니다. JavaScript 점수는 Python/scikit-learn의 199개 기준 표본과 1e-12 이내로 일치하는지 매 배포에서 검사합니다.

새롭게 실제 관측한 4시간봉의 통과·관망 판단을 `decisions/`에 기록합니다. 모델 점수, 돌파 여부, 관측 시각, 모델 해시를 보존합니다. 각 계좌의 `ledger/`도 이전 기록 해시를 잇습니다. 진입·추적 손절 변경·추세 청산은 실제 기록한 시각 이후 시작하는 15분봉부터 적용하며, 갱신 사이에 놓친 과거 주문을 소급 체결하지 않습니다.

`experiment.json`은 공통 시작 시점과 모델 식별 정보를 보존합니다. 이미 시작한 계좌 파일이 빠지면 새 $10,000 계좌로 자동 재생성하지 않습니다.

## 검증 상태

`research.json`은 2022-01-01~2026-08-31 Binance 선물에서 시간순으로 평가한 결과입니다. 원자료의 SOL 누락 480봉은 공식 일별 파일로 보완한 결과를 사용합니다. 현재 모의계좌는 Hyperliquid이므로 거래소·펀딩 차이가 남습니다.

이전 연구에서 기본 6 ATR 방식이 더 높은 누적 수익을 냈고, 부스팅은 낮은 낙폭의 후보였습니다. 최근 약 20일은 모든 후보가 손실이었으며 부스팅은 종료 거래 2건뿐이었습니다. 거래 수와 관측 기간만 채웠다고 실전 검증 완료로 자동 표시하지 않습니다.

초기 `replay.json`은 같은 시작 자료로 고정한 짧은 과거 재현이며, 별도 `state.json`의 앞으로 발생하는 모의 성과와 구분합니다. 과거 재현의 가격 정보는 학습 종료 이후인지 확인합니다. 모든 계좌의 수익과 손실을 그대로 남겨 비교합니다.
